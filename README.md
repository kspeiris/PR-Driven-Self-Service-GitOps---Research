# PR-Driven Self-Service GitOps - Research

This repository contains the research documentation, analysis, and proposals related to the **PR-Driven Self-Service GitOps** project.

## Directory Structure

- **702 Docs**: Contains project proposal documents (e.g., `Project_702_Proposal_01.html`).
- **Research Analysis**: Contains detailed analysis documents, overviews, and Plural analysis reports.
- **Other Docs**: Additional documentation related to the research.

## Purpose

The main objective of this repository is to track all the foundational research, initial analyses, and proposal drafts for implementing a PR-driven, self-service GitOps model.

## Future Work

- Define standard PR templates for self-service deployments.
- Finalize the automated review pipelines and governance rules.
- Integrate the findings into a production-ready OpenChoreo configuration.
